# Bike Store Landing Page 🚴
> My first complete web development project

![Website Preview](/src/images/preview.png)

## About the Project

This is a landing page for an online bicycle store. The site features a catalog of bicycles and parts, a contact form for consultations, and complete store information including phone numbers and address.

## Features

- 🚴 **Bicycle Catalog** — browse different types of bikes
- 🔧 **Parts Section** — find bicycle components and accessories
- 📝 **Contact Form** — request consultation with store specialists
- 📞 **Contact Information** — phone numbers and store address
- 📱 **Responsive Design** — works on all devices

## Technologies Used

- **HTML5** — semantic markup
- **CSS3/SCSS** — styling and preprocessor
- **BEM methodology** — clean and maintainable code structure
- **Responsive design** — mobile-first approach

### Key Techniques:
- Flexbox and Grid layouts
- Animations
- Pseudo-classes (`:hover`, `:active`, `:focus`, `::after`)
- SCSS variables and mixins
